# `dm.enemy_hp` — ХП противников в ушах (World of Tanks 2.4.1+)

Лёгкий, точный и неинтерактивный мод для отображения текущего количества очков прочности (HP) команды противника отдельной числовой колонкой **слева от иконок вражеских танков** в правых «ушах».

---

## Основные возможности

- **Чистая числовая колонка без рамок и подложек** (`tabular-nums`, белый шрифт с мягкой тенью), построчно выровненная по строкам правых «ушей» WoT.
- **Точный порядок строк**: 100% повторяет сортировку `PlayersPanel` (`EnemyItemsCollection` + `VehicleInfoSortKey`) в любом режиме боя (15×15, 7×7 и т.д.).
- **Нулевой рассинхрон ХП**:
  - На старте боя выставляется базовый `maxHealth` из данных арены.
  - При первом засвете с **Улучшенной закалкой / Полевой модернизацией** `maxHealth` и текущее ХП автоматически корректируются без потери нанесённого ранее урона.
  - Мгновенное обновление как в круге отрисовки (AOI), так и **за пределами 564 м** через серверные вызовы `BattleFieldCtrl` и `ClientArena`.
  - **Сохранение ХП в отсвете**: при уходе танка в отсвет (`onLeaveWorld` / `stopVehicleVisual`) последнее известное ХП сохраняется.
  - **Мгновенная синхронизация при повторном засвете**: блайнд-урон, пожар, таран или падение в отсвете немедленно подтягиваются по серверному значению (`setVehicleVisible` / `onEnterWorld`) + страховочная сверка каждые `0.5с`.
  - **Смерть и оверкилл**: отрицательные значения всегда зажимаются в `0`, погибшие танки по умолчанию скрывают цифру (либо показывают тусклый `0`, если включить `showDeadZero`).
- **Умная видимость**: автоматически скрывается при скрытых ушах (`hidden`), нажатии `V` (скрытие HUD), `Tab`, открытии Esc/модальных окон и в камере убийцы (`hideInKillcam`).

---

## Конфигурация (`mods/configs/dm_enemy_hp/config.json`)

При первом запуске создаётся автоматически. Повреждённые или отсутствующие поля безопасно восстанавливаются из дефолтов.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `enabled` | `true` | Включить/выключить отображение |
| `fontSize` | `14` | Размер шрифта (px) |
| `rowHeight` | `25` | Высота строки правых «ушей» (px) |
| `colWidth` | `54` | Ширина колонки ХП (px) |
| `topY` | `56` | Базовый вертикальный отступ сверху экрана |
| `offsetX` / `offsetY` | `0` / `0` | Тонкая пользовательская подстройка позиции |
| `modeRightOffsets` | `short: 116`, `medium: 212`, `medium2: 212`, `large: 336` | Отступ от правого края экрана до ушей по режимам |
| `colorAlive` | `#FFFFFF` | Цвет ХП техники в засвете |
| `colorUnspotted` | `#FFFFFF` | Цвет ХП техники в отсвете |
| `unspottedAlpha` | `1.0` | Прозрачность для техники в отсвете (`0.05..1.0`) |
| `showDeadZero` | `false` | Показывать `0` у уничтоженных танков |
| `colorDead` / `deadAlpha` | `#8C8C8C` / `0.55` | Цвет и прозрачность `0` у уничтоженных танков |
| `hideInKillcam` | `true` | Скрывать в камере убийцы |
| `reconcileIntervalSec` | `0.5` | Интервал страховочной сверки ХП |
| `debugLog` | `false` | Подробное логирование в `mods/configs/dm_enemy_hp/enemy_hp.log` |

## Тестирование и сборка

### Запуск тестов (Python 2.7)
```powershell
C:\Python27\python.exe -m unittest discover -s tests -v
```

### Сборка `.wotmod`
Сборка компилирует все `.py` через `F:\game\TankiEU\World_of_Tanks_EU\win64\python27.dll` в `ZIP_STORED` архив `dist\dm.enemy_hp_1.0.0.wotmod`:
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

### Установка в клиент игры (с бэкапом старой версии)
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Install
```
